## Трек A (ML) — готово

**Что сделали:** пакет `scene_mm`. Это расширение SCENE, где клетки, гены **и поверхностные белки** (CITE-seq) — точки в одном общем 16-мерном пространстве.

- Для РНК можно выбрать правдоподобие: ZIP, NB, decoupled или Poisson.
- Для белков — правдоподобие NB с отдельным фоновым слагаемым у каждого белка.
- Новые доноры добавляются через fold-in: гены, белки и батч-эффекты заморожены.
- Данные: PBMC (217 белков) и NeurIPS (134 белка), по 30 тыс. клеток.
- Всего 160 прогонов на кластере.

| Гипотеза (записана до результатов) | Результат |
|---|---|
| H1: NB описывает РНК лучше ZIP | ✓ NLL на отложенных данных лучше. ✗ Вариант decoupled ничего не дал. |
| H2: белки помогают различать типы клеток | ✓ NMI на PBMC вырос с 0.62 до 0.70 (вес белков 3) |
| H3: белок оказывается рядом со своим геном | ✓ Медианный перцентиль 0.4–3%. Неудачи — белки без сигнала. |
| H4: fold-in лучше подхода без обучения | ✓ Перенос меток 0.90 против 0.48 |
| H5: на новых донорах результат сравним с totalVI | ✓ Ничья: 0.918 против 0.916 (macro-F1 0.779 против 0.777) |

**Дополнительные проверки**

- **Изотипические контроли.** Модель примерно на 99% объясняет их счёт фоном. У настоящих белков медианная доля сигнала — 42%.
- **Перебор веса белков.** Лучший вес — 3: кластеризация лучше, а модель РНК почти та же.
- **Предсказание белков нового донора только по РНК** (8 доноров, Pearson):
  - totalVI — 0.53;
  - kNN — 0.49;
  - SCENE с kNN в латентном пространстве — 0.47;
  - SCENE NB — 0.43;
  - SCENE ZIP — 0.41.

  **Для SCENE результат отрицательный.** Читать белок по одному расстоянию слишком жёстко — это плата за интерпретируемость.

**Мелкие открытые задачи**

- Добавить бейзлайн для предсказания белков: РНК его собственного гена.
- 3D подходит для картинок, а для тонкой структуры нужно 16D.

**Что трек A передаёт треку B**

- В каждом прогоне `results/<run>/` есть файл `embedding.h5ad`:
  - клетки — в `obsm`;
  - гены и белки — в `varm`.
- Там же лежит `train_log.json` с метриками.
- Прогон загружается функцией `scene_mm.train.load_run`.

## Трек B (биология и статистика) — не начат

**Вопрос:** образуют ли гены ответа на лекарства и мишени лекарств компактные группы в пространстве? Выдерживает ли это честный нулевой тест и проверку на технические факторы?

1. **Эмбеддинги.**
   - Уже есть: SCENE на данных GR/дексаметазона и TCR (из воспроизведения) и PBMC/NeurIPS из трека A.
   - Обучить: IFN-β и подвыборка sci-Plex, по 3 сида.
   - Бейзлайны: нагрузки PCA, LDVAE, GenePT.
2. **Наборы генов.**
   - Гены ответа на IFN-β и GR.
   - Мишени соединений sci-Plex (Open Targets / DrugBank) и классы их механизма действия (MoA).
   - Технические контрольные наборы: рибосомные, митохондриальные, клеточного цикла, стресса диссоциации и гены с частыми пропусками.
3. **Честный нулевой тест.** В статье компактность модуля сравнивают со случайными генами, выбранными равномерно. Мы будем сравнивать со случайными генами **того же уровня экспрессии и той же доли детекции**.
4. **Аудит артефактов.** Насколько положение гена объясняется средней экспрессией, долей пропусков и дисперсией (R², чистота kNN). Проверяем на всех эмбеддингах, включая варианты из трека A.
5. **Тест MoA на sci-Plex.**
   - Для каждого лекарства считаем сдвиг в пространстве генов (обработка против контроля).
   - Проверяем, сдвигают ли похоже лекарства с одинаковым MoA.

**Возможный главный вывод:** *«Мультимодальное совместное пространство делает программы ответа на лекарства читаемыми и устойчивыми к техническим артефактам»*. Обратный вывод тоже стоит опубликовать.
